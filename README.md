# GenAI-driven E-commerce Fulfillment Decision Support System

## Overview
This project builds a GenAI-powered decision support system for e-commerce fulfillment analysis.  
It allows users to input natural language queries and automatically translates them into structured data analysis workflows.

## Key Features
- Natural language → structured analysis mapping  
- Business metric calculation (late_rate, avg_days_late)  
- Multi-stage diagnosis: detect → locate → validate  
- Rule-based policy constraint to ensure reliable outputs  

## Tech Stack
- Python  
- SQL  
- LLM / rule-based logic  
- Vector database (Chroma)
